## 分析维度

每个项目的分析包含：
1. **场景问题**：按真实使用场景说明（角色 + 痛点 + 介入 + 效果）
2. **组成结构与技术组件**：目录结构 + 技术栈 + 数据流/协作流
3. **前 10 结构性优越点**：A类（资源聚合）侧重思维工具/思维工程/场景问题；B类（代码架构）侧重架构设计/技术选型/工程实践
4. **前 10 优化增强点**：具体可操作的改进方向
5. **ProcessOn 结构性全景图**：架构图 + 永久分享链接
6. **幕布大纲文档**：结构化大纲
