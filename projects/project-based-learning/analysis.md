- [ ] 二、知识沉淀
  - [ ] 1. 前10优越点
    - [ ] 第1组（分类与收录）
      - [ ] 优越1：以主语言为第一维切中自学者真实决策入口（先定语言再定领域）
      - [ ] 优越2："project-based"作为收录第一性原则，用编辑器门槛定义质量，只留"看完能做出东西"
      - [ ] 优越3：三级分类（语言→应用域→框架）精度高，"我要用React练手"直达#### React子节
      - [ ] 优越4：自研diff感知linter，只校验PR新增内容，CI快且反馈聚焦
      - [ ] 优越5：对反爬域名工程化降级而非误杀，不可自动验证的降为"请人工确认"
    - [ ] 第2组（保鲜与治理）
      - [ ] 优越6：死链巡检带状态持久化（link-rot-state.json），避免同一条死链反复告警
      - [ ] 优越7：多部分系列用结构化缩进格式，标题+Part1/Part2聚成一个条目，跟练完整
      - [ ] 优越8：利益冲突申报作为贡献纪律，强制作者/关联声明，防自我推广灌水
      - [ ] 优越9："免费无墙"硬门槛，源头排除付费墙/登录墙/newsletter订阅，把"打开即学"做成承诺
      - [ ] 优越10：stale-prs自动治理，机器人标记/关闭陈旧PR，维护者精力集中在有效贡献
  - [ ] 2. 前10优化点
