- [ ] 二、知识沉淀
  - [ ] 1. 前10优越点
    - [ ] 第1组（边界与组织）
      - [ ] 优越1：User-invoked/Model-invoked二元分类给技能划边界，编排型与纪律型分开，防技能图递归失控
      - [ ] 优越2：以"四大失败模式"组织技能（没做想要的/太啰嗦/代码不工作/大泥球），问题驱动非工具罗列
      - [ ] 优越3：ask-matt作为技能路由器，帮用户判断当前场景该用哪个技能，降低选择负担

      - [ ] 优越5：code-review双轴并行子Agent，Standards（规范+坏味道）与Spec（忠实实现）各盯一轴互不污染
    - [ ] 第2组（工程与可持续）
      - [ ] 优越6：small/composable/model-agnostic反"大框架绑架"，白盒零件把工程控制权交还工程师
      - [ ] 优越7：双轨分发（订阅式插件+可fork拷贝），并主动警告"别两个都装否则技能重复"
      - [ ] 优越8：skills/按生命周期分区（engineering/productivity/deprecated/in-progress/misc），质量信号显式化
      - [ ] 优越9：changesets驱动版本同步，npm包与Claude插件版本一致性做成发布门禁
      - [ ] 优越10：把经典软件工程原则（Pragmatic Programmer/DDD/Kent Beck/Ousterhout深模块）编码成可调用纪律
