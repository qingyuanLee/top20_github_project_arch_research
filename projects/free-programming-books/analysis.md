- [ ] 一、项目回顾
  - [ ] 1. 一句话结论：按"语言×资源类型"双维切分的免费编程书籍/课程聚合，非营利基金会治理，7 个 CI workflow 工程化
  - [ ] 2. 场景问题
    - [ ] 场景一：预算为零想系统学编程的学生与自学者——按 46 语言 + 主题预分类，CC BY 4.0 直链官方免费版，30 分钟建书单
    - [ ] 场景二：多语言母语者想读母语教材——books/ 按 ISO 639 分 46 个 .md，中文用户直接开 -zh.md 不用筛翻译
    - [ ] 场景三：贡献者提交一本发现的免费好书——CONTRIBUTING 给 6 类定义与格式规范，CI 自动 lint，不懂 Git 可开 Issue
    - [ ] 场景四：教育工作者选教材——一个仓库覆盖书籍+课程+速查+题库+播客全套
  - [ ] 3. 组成结构
    - [ ] books/：核心 46 个按语言分的书籍列表（英文另分 langs/subjects）
    - [ ] courses/：39 个按语言分的免费在线课程；casts/：18 个播客/录屏
    - [ ] more/：速查表、交互式教程、playgrounds、OJ 题单
    - [ ] docs/：CONTRIBUTING / CODE_OF_CONDUCT / HOWTO；scripts/：rtl_ltr_linter.py
    - [ ] .github/：7 个 Actions workflow + PR 模板 + dependabot；_config.yml Jekyll 部署 Pages
  - [ ] 4. 技术组件
    - [ ] 6 类资源 MECE 分类：Books/Courses/Interactive/Playgrounds/Podcasts/Problem Sets
    - [ ] 格式 schema：`* [书名](URL) - 作者 (格式)`，空行规则精确到行
    - [ ] 7 个 CI：fpb-lint（字母序/格式）、check-urls（死链）、rtl-ltr、detect-conflicting-prs、comment-pr、issues-pinner、stale
    - [ ] URL 权威优先级：作者官网>出版社>第三方，禁网盘（Drive/Dropbox/Mega）
    - [ ] 双站点分发：GitHub Pages 静态站 + 动态搜索站；CC BY 4.0；Free Ebook Foundation 非营利
  - [ ] 5. 验证：stars=397067，来源=GitHub API（实时返回），排名 #5
- [ ] 二、知识沉淀
  - [ ] 1. 前 10 结构性优越点
    - [ ] 组 1（1-5）
      - [ ] 优越点1：按"语言×资源类型"双维度切分内容
        - [ ] 46 个语言文件，非英语母语直进自己语言；英文还能按语言/主题二次切分
      - [ ] 优越点2：6 类资源的 MECE 分类法
        - [ ] 书/课程/交互/playground/播客/题单互不混淆，按学习偏好选类型
      - [ ] 优越点3：CI 自动 lint 字母序与格式
        - [ ] fpb-lint 把空行数/分隔符/排序变硬门禁，维护者只看内容质量
      - [ ] 优越点4：链接存活自动检查
        - [ ] check-urls.yml 定时查所有 URL，比人工巡检高效一个数量级
      - [ ] 优越点5：RTL 语言专门 lint
        - [ ] rtl_ltr_linter.py 处理阿拉伯/希伯来/波斯语方向，覆盖边缘语言工程细节
    - [ ] 组 2（6-10）
      - [ ] 优越点6：明确的 URL 权威性优先级规则
        - [ ] 作者官网>出版社>第三方，统一后不用争论该链哪个镜像
      - [ ] 优越点7：不收网盘链接的准入红线
        - [ ] 禁 Drive/Dropbox/Mega，坚持官方地址，长期可维护性高
      - [ ] 优越点8：新手友好的双入口贡献路径
        - [ ] 不懂 Git 开 Issue 由维护者转 PR，懂 Git 直接 fork，门槛降到会开浏览器
      - [ ] 优越点9：非营利基金会治理 + CC BY 4.0
        - [ ] 基金会运营不因创始人兴趣转移停更，CC BY 允许转载且要求署名
      - [ ] 优越点10：双站点分发（静态 + 动态搜索）
        - [ ] 静态站浏览打印 + 动态搜索站实时检索，GitHub README 内嵌搜索框
  - [ ] 2. 前 10 优化增强点
    - [ ] 组 1（1-5）
      - [ ] 优化点1：条目无 star 数/评分字段，无法横向比较
        - [ ] 只有书名+作者；建议加 Goodreads 评分字段由 CI 自动拉取
      - [ ] 优化点2：无"难度等级"标签
        - [ ] 入门/进阶混在字母序列表；建议分 Beginner/Intermediate/Advanced 子节
      - [ ] 优化点3：无"最后更新年份"字段
        - [ ] 不强制标年份；建议加 (2023) 标注，超 10 年未更新标灰防学过时知识
      - [ ] 优化点4：搜索站只支持书名/作者，无高级筛选
        - [ ] 单输入框；建议加语言/难度/格式/年份 facets 组合查询
      - [ ] 优化点5：英文书按语言/主题双索引存在重复
        - [ ] 同一本书在 langs 与 subjects 维护两次；建议单一数据源+自动生成双视图
    - [ ] 组 2（6-10）
      - [ ] 优化点6：CI 只 lint 格式，不 lint 内容质量
        - [ ] 查不出"其实不免费/不是编程书"；建议加 AI/LLM 内容审核 bot
      - [ ] 优化点7：无读者反馈/点赞机制
        - [ ] 不知哪些链接真被用到；建议搜索站加 👍/👎 反哺推荐排序
      - [ ] 优化点8：Hacktoberfest 期间贡献质量波动
        - [ ] 活动季低质 PR 增多；建议加质量分 bot 对可疑 PR 自动 ask for evidence
      - [ ] 优化点9：无 API/数据导出
        - [ ] 全在 .md；建议 CI 把 .md 转 JSON 发布到 GitHub Releases 供第三方消费
      - [ ] 优化点10：docs/ 多语言翻译进度不可视
        - [ ] 缺翻译覆盖率仪表盘；建议加翻译进度面板供贡献者认领缺口
